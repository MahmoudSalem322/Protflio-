## Content dashboard

The portfolio content is managed at `/admin`. Sign in with the dashboard password to edit site settings, navigation, hero, about, services, projects, experience, contact links, and the password itself. Changes are written to `data/content.json` (override with `PORTFOLIO_CONTENT_FILE`) and appear on the public site on the next request.

The first sign-in password is read from `ADMIN_PASSWORD` and hashed into `data/admin.json`; later password changes are made from the dashboard. Set `SESSION_SECRET` to keep sessions stable across restarts. All runtime data lives in `data/` by default (override with `PORTFOLIO_DATA_DIR`) and is gitignored.
